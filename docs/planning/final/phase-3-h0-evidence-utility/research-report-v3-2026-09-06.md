## What changed

The new primary outcome is focal behavioral pass yield, conditional on a common evaluator-only scaffold. Each model receives hunk-only, local-context and dependency-selected inputs. Expanded arms share a 32 KiB source budget. Parent-only Tree-sitter retrieval adds enclosing declarations and ranked identifier-related declarations, callers and tests, with ambiguity and parse-error records. This is a bounded syntax-based retrieval policy, not a semantic dependency graph.

Actual Git base/parent blobs must reproduce the conflict and reference mapping. Every tracked scaffold file, including symlink objects, is checked against the original Git merge. References never enter prompts. Build and test run without network or credentials in Bubblewrap; three successful reference runs and at least two compiling, behavior-changing failing mutations are required. Test completion patterns reject an empty successful exit. These finite checks support only their declared behavior, not full semantic equivalence.

Both APIs have frozen settings, separate reasoning parsing, raw request/response receipts, explicit halts and retained malformed/truncated outputs. A provider stops at its first 429 or completed fixed matrix. No answer retries or hidden retries after interrupted requests are allowed. There is no dollar cap. A single development-only token-ceiling extension is implemented under the predefined truncation rule; feasibility results do not trigger it.

Baselines are keep-ours, keep-theirs, longer-side, actual Git union, Git text, GNU diff3, Mergiraf and always-halt. Structural engines receive the same scaffold-conditioned focal problem. Their outputs and status layers are saved, so unrelated unresolved conflicts cannot unfairly depress their performance. Infrastructure failures invalidate a study; genuine abstentions remain in coverage accounting.

The [instrument report](../../../../evidence/h0/v3-research-2026-09-06/README.md) gives exact commands, assumptions, source links and platform limits. ## Research conclusions retained and corrected

The user-supplied survey identifies useful sources but does not establish that exact-match misses hide a semantic advantage. This experiment measures that question directly with executable checks. [Merge-Bench](https://homes.cs.washington.edu/~mernst/pubs/merge-bench-icpr2026.pdf) distinguishes historical matching and behavioral evaluation; its archive cannot be silently pooled without event identities. [ConGra](https://github.com/HKU-System-Security-Lab/ConGra) is an acquisition source, not a supplied executable oracle.

[ConflictAgent's calibration](https://arxiv.org/html/2607.27674v1) reports 117 true positives and zero false positives in a finite sample. It does not prove perfect precision on new resolutions. LLM judging is therefore excluded from the primary endpoint. Weave performance claims likewise establish neither an absolute structural ceiling nor the correctness of arbitrary output; Weave, full Rover graphs and LLVM extraction are outside this implementation.

The solver integrations follow [Inception's completion API](https://docs.inceptionlabs.ai/api-reference/chat/create-a-chat-completion) and [MiniMax's OpenAI-compatible text API](https://platform.minimax.io/docs/api-reference/text-chat-openai). Returned model identifiers and token usage are retained, but hosted aliases do not pin immutable model weights. Costs are estimates from recorded token usage, not billing invoices.
