This is a prospective futility/readiness rule: there is no observed margin for the retained gate, so increasing sample size under those point estimates is not the remedy. Do not run another acquisition round in response to that failure. A validity failure yields **INVALID INSTRUMENT**, not a null or positive result. Repairing a verified implementation defect requires a preserved failure record and a new protocol version; it must not serve as an undeclared outcome-driven policy search. Any substantive new selector or population after this stopping decision is a separately declared exploratory study, not continuation of the same confirmation attempt.
