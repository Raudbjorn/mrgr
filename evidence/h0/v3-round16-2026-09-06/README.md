## Declaration-name defect found during static review

The current selector takes the first descendant node of type `identifier` with a name/declarator field. In Go this can select a method receiver instead of the method name; it also omits `type_identifier` and `field_identifier` declaration names. A [synthetic regression](selector-name-regression.json) demonstrates an unrelated method being ranked as a direct reference because its receiver is named `Read`, while the referenced `Store` type receives only lexical-overlap rank.

An isolated [two-line patch](selector-name-repair.patch) retains AST indentation depth and selects the shallowest named identifier descendant across identifier node types. The [runnable check](selector-name-regression.mjs) passes against the frozen original and the isolated repaired module. [Provenance](selector-name-repair-provenance.json) records both source hashes. This repairs the demonstrated name-extraction error; it does not establish full semantic binding or empirical utility.
